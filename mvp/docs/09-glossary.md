# Umbrella MVP · 9. Глоссарий

Термины, которые используются в документах набора MVP. Сначала латинские термины, затем русские, внутри групп по алфавиту.

## Термины

| Термин | Значение |
| --- | --- |
| ack (подтверждение) | 1) ответ источнику, что событие получено и записано; 2) подтверждение инцидента дежурным в PagerDuty, на дашборде инцидентов или по ссылке из резервного сообщения |
| AD | Active Directory, пример корпоративного каталога пользователей и групп |
| ADR | запись в журнале архитектурных решений |
| AIOps | платные функции автоматической корреляции и шумоподавления на основе статистики и машинного обучения; в MVP не используются |
| backoff | увеличение паузы между повторными попытками |
| BPMN | нотация описания бизнес-процессов; схемы БП близки к ней |
| break-glass | локальная учётная запись аварийного администратора на случай недоступности IdP или каталога; учётные данные в OpenBao, MFA, аудит каждого входа |
| C4 | нотация описания архитектуры по уровням: контекст, контейнеры, компоненты, развёртывание |
| CEL | Common Expression Language, безопасный язык выражений для правил и маппинга |
| circuit breaker | автомат, который после 5 ошибок подряд или 60 с без ответа прекращает попытки отправки в PagerDuty и считает канал деградировавшим; отсчёт 2 мин до резервного оповещения при этом продолжается |
| CMDB, карта CMDB | база КЕ и связей; в Umbrella строится из данных мониторинга |
| Context Builder | контейнер, который генерирует дашборды инцидентов в Grafana |
| dedup_key | ключ события в PagerDuty; у Umbrella формат umb-‹id тревоги› |
| DLQ | очередь неразобранных сообщений; в Umbrella поток events.dlq |
| DMZ | сетевая зона между интернетом и внутренними зонами; в ней reverse proxy с WAF и egress-прокси |
| dry-run | прогон настройки на реальных данных без публикации |
| egress-прокси | единственная точка выхода Umbrella во внешние сети, пропускает только адреса из списка |
| escalation policy | правила PagerDuty: кого и через сколько оповещать при отсутствии подтверждения |
| external_id | идентификатор события в источнике; с источником даёт ключ inbox |
| Fallback Notifier | контейнер резервного оповещения |
| GitOps | развёртывание из описания в Git: состояние кластера приводится к описанию автоматически |
| Grafana | система визуализации телеметрии; Umbrella генерирует в ней дашборды инцидентов, данные Grafana берёт из хранилищ метрик, логов и трейсов |
| Grok | шаблоны разбора текстовых строк на поля |
| heartbeat | регулярный сигнал «жив» во внешний сервис; его отсутствие поднимает тревогу |
| HMAC | подпись сообщения общим секретом для проверки подлинности webhook |
| HPA | автоматическое изменение числа реплик в Kubernetes по нагрузке |
| IdP | корпоративный поставщик удостоверений: вход пользователей и MFA |
| Inventory DB | приложение учёта инвентаря ЦОД в духе NetBox (площадки, стойки, устройства, IP, кабели); источник физических КЕ для карты CMDB и получатель статусов тревог |
| inbox | таблица полученных событий для отбрасывания повторов |
| ITSM | система управления ИТ-услугами (инциденты, проблемы, изменения); в MVP не интегрируется |
| JSONata | язык запросов и преобразования JSON для маппинга полей |
| LDAP, LDAPS | протокол доступа к каталогу; LDAPS — LDAP поверх TLS, порт 636 |
| low-code | настройка в визуальном редакторе из блоков |
| mTLS | взаимная проверка сертификатов обеих сторон соединения |
| MTTA, MTTR | среднее время до подтверждения и до устранения |
| OIDC | OpenID Connect, протокол единого входа через IdP |
| OpenBao | хранилище секретов Umbrella (×3, Raft); остальные части хранят только ссылки |
| OpenTelemetry | открытый стандарт трассировок и метрик, его использует сама Umbrella |
| outbox, transactional outbox | таблица исходящих сообщений; изменение тревоги и запись outbox идут в одной транзакции, затем сообщение публикуется с повторами |
| p95 | 95-й процентиль: 95% значений не больше указанного |
| PDB | ограничение Kubernetes на число одновременно останавливаемых реплик |
| PITR | восстановление БД на любой момент времени по WAL |
| PubAck | подтверждение NATS JetStream, что сообщение записано в поток |
| RACI | матрица ответственности: R делает, A отвечает, C консультирует, I информируется |
| Raft | алгоритм согласованной репликации, используется в OpenBao |
| RBAC | управление доступом на основе ролей |
| RE2 | движок регулярных выражений с гарантированным временем работы |
| RED | методика для сервисов: Rate, Errors, Duration |
| routing_key | ключ интеграции сервиса PagerDuty |
| RPO, RTO | допустимая потеря данных и допустимое время восстановления после аварии |
| S3 | объектное хранилище для бэкапов, размещается на другой площадке или в другом регионе |
| SAST | статический анализ кода на уязвимости |
| SBOM | перечень компонентов и зависимостей образа |
| SCIM | протокол передачи пользователей и групп из IdP в приложение (SCIM 2.0) |
| SIEM | система сбора и анализа событий безопасности; получает журнал аудита Umbrella |
| SLO, SLA | целевой уровень сервиса; соглашение об уровне сервиса с бизнесом |
| SSRF | атака, при которой сервер выполняет запрос к внутреннему адресу по указанию атакующего |
| STRIDE | классификация угроз: подмена, изменение, отказ от действий, раскрытие, отказ в обслуживании, повышение прав |
| USE | методика для ресурсов: Utilization, Saturation, Errors |
| WAF | межсетевой экран уровня приложений перед входящими webhooks |
| WAL | журнал предзаписи PostgreSQL; используется для репликации и восстановления |
| Watchdog | контейнер самоконтроля: сквозная проба, проверка каналов, heartbeat |
| webhook | HTTP-запрос, которым система сама передаёт событие |
| алерт / тревога / инцидент | алерт — сообщение о проблеме от источника или в PagerDuty; тревога — все события с одним ключом дедупликации внутри Umbrella; инцидент — в PagerDuty объект, созданный по тревоге, а на дашборде инцидентов MVP — тревога, переданная в PagerDuty (одна на проблему) |
| бизнес-услуга | то, что видит клиент; собирается из ИТ-сервисов |
| блок | шаг коннектора или правила в конструкторе |
| вероятная причина | тревога, которая скорее всего вызвала другую: в MVP USE-тревога КЕ, связанная с RED-тревогой её сервиса |
| группа каталога | группа пользователей в корпоративном каталоге (например, UMB-*), к которой в Umbrella привязаны роль, область и предустановка дашборда |
| дашборд инцидентов | страница веб-интерфейса со списком инцидентов, фильтрами, поиском и действиями |
| запасная платформа оповещения | второй сервис оповещения на случай отказа PagerDuty; в MVP не используется, рассмотрена в целевой архитектуре |
| инвентарь | список объектов источника, из которого строится карта CMDB |
| ИТ-сервис | технический сервис, из которого собрана бизнес-услуга |
| КЕ | конфигурационная единица: приложение, БД, хост, под, облачная группа |
| кеш дежурств | копия расписаний и escalation policy PagerDuty в PostgreSQL, нужна, когда PagerDuty недоступен |
| ключи распечатывания | доли ключа (Шамир 3 из 5) или внешний ключ auto-unseal, без которых OpenBao после перезапуска не открывает секреты |
| коннектор | собранный из блоков способ забирать данные из источника и подтверждать получение |
| курсор | позиция в источнике, до которой события уже забраны |
| логическая группа | устойчивая единица в облаке, внутри которой меняются инстансы |
| нормализация | приведение события к единой модели |
| область | часть РСМ, в которой действует роль: бизнес-услуги, ИТ-сервисы, команды, коннекторы и источники |
| окно обслуживания | период работ, когда тревоги пишутся, но не отправляются |
| основной канал оповещения | PagerDuty |
| ПДн | персональные данные |
| плавающий ID | ID облачного ресурса, меняющийся после перезагрузки |
| предустановка дашборда | набор фильтров, столбцов, группировки, сортировки, виджетов и связей контекста, который группа каталога видит по умолчанию |
| привязка группы | связь группы каталога с ролью, областью и предустановкой дашборда; меняется в два ключа |
| резервные каналы оповещения | почта и webhook, по которым Umbrella оповещает, если PagerDuty не принял тревогу error или critical за 2 мин |
| резервные контакты | контакты команды сервиса на случай, когда кеш дежурств пуст или старше 24 ч, и для эскалации через 10 мин без подтверждения |
| роль | набор разрешений на функции, например dashboard.view, incident.ack, connector.edit |
| РСМ | ресурсно-сервисная модель |
| связи контекста | low-code правила: какие КЕ из карты CMDB и какие панели метрик, логов и трейсов попадают на дашборд инцидента в Grafana |
| сигнал | тип проблемы из справочника, входит в ключ дедупликации |
| схлопывание | объединение событий разных источников про одну проблему в одну тревогу |
| хранилище секретов | OpenBao |
| шаблон источника, шаблон события | правила перевода полей источника в единую модель; текст алерта для дежурного |

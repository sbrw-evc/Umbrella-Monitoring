# Zabbix

Zabbix 7.0 LTS (сервер, веб-интерфейс на nginx, PostgreSQL 17 и агент 2, который наблюдает сам за собой) в общей сети `umbrella`.

```sh
cp .env.example .env   # задайте ZABBIX_DB_PASSWORD
docker compose up -d
```

Для Zabbix 8.0 раскомментируйте в `.env` строки с образами 8.0.

Интерфейс: http://localhost:8081, вход `Admin` / `zabbix` (смените пароль при первом входе). Внешние агенты подключаются к порту 10051; чтобы он был доступен не только с этой машины, задайте `ZABBIX_BIND=0.0.0.0`.

## Подключение к Umbrella

Проще всего: в Umbrella **Коннекторы → Подключить источник → Zabbix** — токен, коннектор и публикация делаются сразу, а способ оповещения выдаётся с уже подставленными адресом и токеном (тогда шаги 1 и 2 сводятся к импорту файла). Вручную:

1. В Umbrella: **Автоматизация → Учётные данные** — создайте Bearer-токен. **Коннекторы** — создайте коннектор из шаблона «Zabbix (тип оповещения webhook)», выберите этот токен в узле webhook и опубликуйте. Адрес приёма — `/api/ingest/<slug>`, по умолчанию `zabbix`.
2. В Zabbix: **Оповещения → Способы оповещения → Импорт**, файл [`umbrella-mediatype.yaml`](umbrella-mediatype.yaml). В способе «Umbrella» задайте параметры:
   - `url` — адрес приёма. Если Umbrella запущена из `deploy/umbrella` на этом же хосте, подходит `http://umbrella:8080/api/ingest/zabbix`;
   - `token` — токен из шага 1.
3. **Пользователи → Пользователи → Admin → Оповещения**: добавьте способ «Umbrella», в поле «Отправлять на» — любое значение, например `umbrella`.
4. **Оповещения → Действия → Действия триггеров**: создайте действие с операцией «Отправить сообщение» пользователю Admin через «Umbrella» и такой же операцией восстановления.

Способ оповещения отправляет поля, которые ждёт шаблон: `event_id`, `host`, `host_group`, `trigger`, `item_key`, `severity` (0–5), `status` (1 — проблема, 0 — восстановление) и `value`. Восстановление приходит с тем же `event_id`, что и проблема, поэтому закрывает ту же тревогу. Ответ Umbrella не из диапазона 2xx Zabbix показывает как ошибку отправки в «Отчёты → Журнал действий».

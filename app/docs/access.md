# Доступ: роли, команды и области видимости

## Роли

У каждого пользователя ровно одна роль. Роль — это набор разрешений `<страница>:<функция>` из каталога (`GET /api/access/catalog`).

| Роль | Что даёт | Кому |
| --- | --- | --- |
| Администратор (системная) | всё, включая страницы, которые появятся позже | администраторы |
| Пользователь (системная) | ничего, только собственный профиль | — |
| Наблюдатель | просмотр инцидентов, карты CMDB, КЕ, сервисов, сервисных окон и ТВ-панелей | всем по умолчанию |
| Дежурный инженер | Наблюдатель + подтверждение, решение и комментарии инцидентов, сервисные окна | смена NOC |
| Владелец сервиса | инциденты (просмотр и подтверждение), карта CMDB, КЕ, сервисы, просмотр сервисных окон; выдавайте вместе с областью «сервисы моих команд» | команды разработки |
| Администратор интеграций | Наблюдатель + коннекторы, учётные данные, правила RED/USE, системы мониторинга, NetBox, изменение КЕ и сервисов, состояние системы | инженеры мониторинга |
| Руководитель NOC | Дежурный инженер + команды, пользователи (просмотр, изменение, блокировка; администраторов меняют только администраторы), ТВ-панели, просмотр и проверка оповещений, состояние системы | начальник смены |

Пять готовых ролей создаются **один раз** — при установке или при первом запуске версии, где они появились, — на языке установки. Это обычные роли: их можно переименовать, изменить и удалить, удалённая роль не возвращается. Если роль с таким названием уже была, готовая не создаётся.

### Роль для новых пользователей

Учётные записи, которые создаёт вход или синхронизация LDAP / AD, Entra ID и NetBox, получают «Роль для новых пользователей», если таблица «Группы → роли и команды» не выдала другую. По умолчанию это «Наблюдатель»; поменять — Роли → роль → «Выдавать новым пользователям» (`PUT /api/roles/{id}/new-users`, право `roles:edit`). Роль администратора выбрать нельзя. Уже созданные пользователи не меняются. Если выбранную роль удалить, новые пользователи получают «Пользователь».

Та же роль ставится, когда таблица групп перестала выдавать пользователю роль (см. [group-mapping.md](group-mapping.md)).

### Пользователь без прав

Если роль не открывает ни одной страницы, после входа человек попадает в профиль и видит баннер «Доступа пока нет» со списком активных администраторов и их почтой.
